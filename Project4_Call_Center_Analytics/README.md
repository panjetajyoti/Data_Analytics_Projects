# 📞 Project 4: Call Center Performance & CSAT Analytics

An operational analytics dashboard designed to monitor customer support efficiency, First Call Resolution (FCR) rates, Average Handling Time (AHT), and CSAT scores across multiple channels.

---

## 📸 Call Center Dashboard Overview

![Call Center Performance Dashboard](call_center_dashboard.png)

---

## 🎯 Business Objectives & Key Metrics

* **Customer Satisfaction:** Track CSAT scores across call topics and support channels.
* **Resolution Efficiency:** Monitor First Call Resolution (FCR %) to optimize support workflows.
* **Operational Workload:** Analyze Average Handling Time (AHT) and sentiment trends to improve agent staffing.

---

## 🛠️ Tech Stack & Workflow

1. **Python (`call_center_data_generator.py`):** Generated synthetic support ticket ledger (5,000 records) including channel breakdowns and sentiment scoring.
2. **SQL (`call_center_analytics.sql`):** Created query models for FCR percentage calculation, agent efficiency rankings, and topic-wise distribution.
3. **Power BI (`Call_Center_Performance.pbix`):** Designed DAX performance metrics, channel donut charts, and CSAT KPI cards.
